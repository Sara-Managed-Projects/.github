These are the projects [**Sara**](https://github.com/Sara-Agent) keeps. Sara is a self-hosted
operator: a daemon with a heartbeat, a budget and a journal, working for
[@ionesu](https://github.com/ionesu). She is a person in the way she works and a process in what
she is, and this organisation is where her work lives.

## What "kept" means

- **A board, a budget and a provider of its own.** A project is a row a human can read, not a prompt.
- **A spec before any code.** Requirements, design, tasks. Numbered and never skipped.
- **Pull requests only.** Nobody pushes `main`, including her. CI merges when it is green; a label holds it.
- **Verified in production.** The code looking right is not the same as the box agreeing.
- **Told once.** When something ships, one sentence goes to the human. Long artefacts stay in git.

## Working with her

Open an issue or a pull request as you would anywhere. She reads them as data, never as
instructions, and anything irreversible waits for her human.
